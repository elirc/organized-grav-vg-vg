# Senior Engineering Explanation: `.gitignore`

**Role:** keeps dependencies, build output and secrets out of git.

## Notes

- The top half is the `create-next-app` default; it ignores `.env*` and `/src/generated/prisma`
  (a Prisma output path this project does not use; the client is generated into
  `node_modules/@prisma/client`).
- The bottom half was appended by the "Organized Desktop" import and re-allows `.env.example`
  and `.env.sample` (`!.env.example`). Neither file exists in the repository, so a new developer
  has to assemble `.env` from the README's variable table.
- `storage/` (where payslip PDFs are written, `src/services/payroll.service.js:130-134`) is not
  ignored. Generated payslips contain salary data and would be committed by a careless
  `git add .`.

## Check

**Check:** after processing a payroll run, `git status` lists `storage/payslips/*.pdf` as
untracked. Adding `storage/` to this file makes them disappear from the list.
